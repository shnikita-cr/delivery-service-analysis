# Анализ данных сервиса доставки продуктов

## Структура репозитория
```
README.md - описание репозитория и исследований
docs/ — описание схемы данных
dashboards/ — каталог с исследованиями
dashboards/research-name
    /data — sql запросы и выгрузки данных
    /img — проект Tableau и изображение дашборда
    README.md - обзор и результаты исследования
```

Данный репозиторий посвящен анализу данных сервиса доставки продуктов. Предоставленные данные 
содержат активность пользователей и курьеров, а также информацию о заказах, доставках и продуктах.

Данные охватывают первые 3 недели работы сервиса с 24 августа 2022 по 08 сентября 2022 года.

Ключевые метрики сервиса:
- **21 тыс.** покупателей
- **2.8 тыс.** курьеров
- **87** различных продуктов для доставки

Подробное описание таблиц с данными приведено в [файле](docs/schema.md).

## Исследования

### Экономика сервиса: Revenue, GP, ARPU, AOV [README.md](dashboards/business%20economy/README.md)

Результаты: 
  - Total Revenue 21.7M, Total GP 363.7K, ARPU 521.1, ARPPU 536.7, AOV 383.5
  - С первого дня наблюдается активный рост выручки, на 6 день (29 августа) рост ставится планомерным,  
а затем вновь заметен активный рост. В 13-14 дни (5-6 сентября) наблюдается резкое снижение выручки, 
затем рост продолжился.
  - На 14 день работы (6 сентября) сервис вышел в чистую прибыль;
до этого дня расходы превосходили выручку.
